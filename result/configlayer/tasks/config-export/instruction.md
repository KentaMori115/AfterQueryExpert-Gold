Configuration flows into configlayer; getting it back *out* is ad-hoc `print(dict)`. Add a `configlayer.export` package: `export_json`, `export_dotenv`, `export_ini`, an `export_config(data, format="json", **options)` dispatching on a case-insensitive name, forwarding the rest, and `export_formats()` returning the three names as a sorted list. `export_path(data, path)` renders and writes at once, taking format from the extension (`.json`, `.env`, `.ini`) unless `format=` overrides, returning that text. Renderers sort keys at each level and accept only mappings with string keys. What they cannot render — a bad value, name or format — raises `ExportError`, a new `ConfigError` subclass, naming the offending dotted path, list elements as `hosts[1]`. `export_config` and `ExportError` import from the top-level package too.

JSON is two-space indented and ends with a newline. Dotenv builds a name per path: segments uppercased, joined by double underscores, the optional `prefix` set in front across a single one, so `db.host` under prefix "app" gives `APP_DB__HOST`, the inverse of `configlayer.env.parse_env`. Segments no environment name can hold (dashes, leading digits) are refused. Values render alike everywhere: booleans true/false, None empty, a list of scalars joined by ", ". Only dotenv quotes, and only where the text needs it — surrounding whitespace, `#`, `=`, a space or a quote — double quotes first, single ones where the text already carries a double, and nothing when it holds one of each, or a line break. INI opens a `[section]` per top-level mapping, one blank line apart, deeper levels flattened into dotted options (`pool.size = 10`); a top-level scalar is an error, and `INILoader`, which parses with interpolation off, must read it back unchanged. `redact_secrets=True` masks secret-bearing keys through `configlayer.secrets.redact` first, leaving the caller's mapping untouched.
