Configuration flows in through configlayer, but getting a resolved config back *out* is still ad-hoc `print(dict)`. Add a `configlayer.export` package holding `export_json`, `export_dotenv` and `export_ini`, an `export_config(data, format="json", **options)` dispatching on a case-insensitive name and forwarding the rest, and `export_formats()` returning the three names as a sorted list. `export_path(data, path)` renders and writes in one call, taking its format from the extension (`.json`, `.env`, `.ini`) unless `format=` overrides, and returning the text it wrote. Every renderer sorts keys at each level and accepts only a mapping with string keys. Whatever it cannot render — a bad value, a name that will not map, an unknown format — raises `ExportError`, new here and a `ConfigError` subclass, naming the offending dotted path, list elements as `hosts[1]`. `export_config` and `ExportError` import from the top-level package too.

JSON is two-space indented and ends with a newline. Dotenv builds a name from each path: segments uppercased and joined by double underscores, the optional `prefix` set in front across a single one, so `db.host` under prefix "app" gives `APP_DB__HOST` — `configlayer.env.parse_env` read backwards. Segments no environment name can hold (dashes, leading digits) are refused. Values render alike everywhere: booleans as true/false, None as empty, a list of scalars joined by ", ". Only dotenv quotes, and only where the text needs it — surrounding whitespace, `#`, `=`, a space, a quote — reaching for double quotes first, single ones where the text already carries a double, and refusing text that carries both kinds or a line break. INI opens a `[section]` per top-level mapping, one blank line apart, deeper levels flattening into dotted options (`pool.size = 10`); a scalar at the top level is an error, and `INILoader`, which parses with interpolation off, must read the result back unchanged. `redact_secrets=True` masks secret-bearing keys through `configlayer.secrets.redact` first, leaving the caller's mapping untouched.
