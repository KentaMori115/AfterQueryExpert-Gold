Merged configuration is stringly typed, so every consumer re-invents `int(cfg["db"]["port"])` with half-checked parsing. Give configlayer a typed reading layer: a new `configlayer.typed` package whose `TypedView` wraps any nested mapping (a merged dict, or `LayeredConfig.as_dict()`), re-exported from the top-level package.

`TypedView` offers `get_str`, `get_int`, `get_float`, `get_bool`, `get_duration`, `get_size` and `get_list`, all taking a dotted key. A missing key — or a None value, which counts as unset — returns the caller's `default` when given, otherwise raises `ValidationError` saying the key is required; a present-but-malformed value raises even with a default, and every message names the full dotted key. Raw indexing and `in` work on dotted keys too, and `scope(prefix)` returns a sub-view whose lookups are relative but whose errors still report full paths.

Conversions are strict: booleans come from real bools or the words true/yes/on/1 and false/no/off/0 (any case); integers from ints (never bools or floats) or plain base-10 strings; lists from real lists or comma-separated strings (items stripped, empty string means empty list, empty items refused, an optional `item=` callable converts each element). Durations return float seconds from numbers or strings of back-to-back `<number><unit>` terms — units w, d, h, m, s, ms in strictly descending order, none repeated, a bare number meaning seconds, so "1h30m" is 5400.0. Sizes return exact int bytes: B/KB/MB/GB/TB scale by 1000, KiB/MiB/GiB/TiB by 1024, units case-insensitive, one optional space, fractional numbers accepted only when the byte count comes out whole — "0.1GB" is exactly 100000000, "1.5B" is refused. Also export `parse_bool`, `parse_duration`, `parse_size`, `parse_items`, plus `format_duration` and `format_size`, which render values back into these grammars (greedy unit decomposition; largest exactly-dividing unit, binary winning ties; zero gives "0s"/"0B").
