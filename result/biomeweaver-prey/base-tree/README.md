# BiomeWeaver

Offline TypeScript laboratory for deterministic authored ecosystems.

BiomeWeaver compiles regions, habitats, calendars, resources, species, cohorts,
seasonal modifiers, feeding rules, reproduction, mortality, and fixed
disturbances. It advances them through immutable fixed-point simulation ticks
and explains every population and resource change through attributed flows.

This repository is **Seed World** — the baseline release. It is a CLI and
TypeScript library only. It is not a real-world ecological forecasting system.

```bash
npm ci
npm run typecheck
npm test
```

Requires Node.js 24.
