Place approved MainGott logo and brand assets here.
Recommended: logo.png, logo-white.png, logo-transparent.png

Presence is not approval. `release-check` only accepts a brand asset that is
listed in `brand.json` with `approved: true` and whose file still matches the
recorded `sha256`. Copy `brand.example.json` to `brand.json` and fill it in.

The production narration voice is approved the same way, in
`voice_profile.json` — see `voice_profile.example.json`.
